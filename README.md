# NakharaX Group — Solar System & Ecosystem

> Engineering intelligence. Building with purpose. Explore our connected solar system of technology and human ambition.

Official interactive static website for **NakharaX Group**.

## Features
- **Cosmic Solar System Theme**: Immersive 3D/Interactive visuals powered by Three.js
- **Bilingual Interface**: Seamless English and Thai bilingual presentation
- **Glassmorphic Navigation**: Sleek, modern floating command header
- **Responsive & Lightweight**: Static assets optimized for performance

## Tech Stack
- HTML5 / CSS3 (Custom properties & modern layout)
- Vanilla JavaScript
- Three.js (Core & Modules)
